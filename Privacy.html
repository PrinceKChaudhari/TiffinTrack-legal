Privacy Policy for TiffinTrack

Last updated: 2026

1. Data We Collect

TiffinTrack collects only the minimum data required for functionality, including Telegram user ID, name, username (if available), menu orders, and payment status.

2. How We Use Data

Data is used only to manage tiffin orders, menus, and payments within the bot system.

3. Data Sharing

We do not sell, rent, or share user data with third parties.

4. Data Storage

All data is stored locally in a JSON-based system controlled by the operator using the bot.

5. Security

We use basic safeguards to prevent data corruption and unauthorized access.

6. Contact

For questions, contact the bot operator via Telegram.
